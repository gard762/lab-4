## Тестирование
Для запуска тестов используется команда `./mvnw test`.
В ходе выполнения работы в формулу площади прямоугольника была намеренно внесена ошибка (сумма вместо произведения сторон).
При запуске сборки `./mvnw clean package` тест `testAreaAndPerimeterNormal` в классе `RectangleTest` упал с сообщением: `expected: <12.0> but was: <7.0>`. Ошибка была исправлена, после чего все тесты успешно прошли.
